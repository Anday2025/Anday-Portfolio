Azure Storage Lab

Praktisk Azure-prosjekt med Storage Account, privat Blob Container, Microsoft Entra ID, RBAC, overvåking, sikkerhet og kostnadskontroll.

Om prosjektet

I dette prosjektet opprettet og administrerte jeg en Azure Storage Account med en privat Blob Container. Formålet var å få praktisk erfaring med sikker fillagring, identitetsbasert tilgang, overvåking og kostnadskontroll i Azure.

Dette har jeg arbeidet med

  • Opprettet en Storage Account og en privat Blob Container, og lastet opp en testfil.
  • Administrerte tilgang med Microsoft Entra ID og RBAC på containernivå, og blokkerte anonym Blob-tilgang.
  • Begrenset nettverkstilgang til valgte nettverk og IP-adresser, og arbeidet med soft delete for beskyttelse mot utilsiktet sletting.
  • Brukte Azure Monitor til å følge transaksjoner, konfigurerte varsler og kontrollerte kostnader i Azure Cost Management.

Praktisk kompetanse

Prosjektet demonstrerer praktisk administrasjon av Azure-lagring, rollebasert tilgang, nettverksbegrensninger, databeskyttelse og driftsovervåking. Det viser også hvordan sikkerhetsinnstillinger og varsler kan kontrolleres i en avgrenset lab.

Praktisk laboratorieprosjekt

Gjennomført som laboratorieøvelse, ikke som en produksjonsløsning.
