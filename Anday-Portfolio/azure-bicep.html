Azure Bicep – Infrastructure as Code

Praktisk prosjekt for å lære automatisert opprettelse og administrasjon av Azure-ressurser ved hjelp av Bicep og Azure CLI.

Om prosjektet

Jeg bruker Azure Bicep og Azure CLI til å definere, opprette og administrere Azure-ressurser med Infrastructure as Code. I denne laben har jeg opprettet og oppdatert en Storage Account gjennom kode, med validering og forhåndsvisning av endringer før utrulling.

Dette har jeg arbeidet med

  • Definerte en Storage Account i en Bicep-mal med parametere, sikkerhetsinnstillinger og ressursmerking.
  • Kompilerte Bicep til en ARM-mal og validerte konfigurasjonen med Azure CLI.
  • Brukte What-If før utrulling, og opprettet og oppdaterte lagringskontoen via Azure CLI.
  • Kontrollerte gjentatt utrulling med What-If og dokumenterte resultatet av sikkerhetskonfigurasjon og ressursmerking.

Praktisk kompetanse

Prosjektet demonstrerer deklarativ ressursadministrasjon, automatisert utrulling og kontroll av infrastrukturendringer. Praktiske læringsmål er å forstå parametere, validering, What-If og idempotens, slik at samme konfigurasjon kan gjenskapes på en kontrollert måte.

Praktisk lab · videre læring

Den dokumenterte Storage-laben er gjennomført. Jeg fortsetter å utvikle kompetansen min innen Bicep, Azure CLI og Infrastructure as Code.
