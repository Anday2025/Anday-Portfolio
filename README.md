# Anday Portfolio

**Personlig porteføljenettside med fokus på IT-drift, Microsoft Azure, IT-infrastruktur og informasjonssikkerhet.**

## Om prosjektet

Dette repositoryet inneholder min personlige porteføljenettside, utviklet for å presentere min utdanning, faglige interesser og praktiske IT-prosjekter.

Jeg har en bachelor i dataingeniørfag fra Høgskulen på Vestlandet (HVL), har bestått Microsoft Azure Fundamentals (AZ-900) og arbeider videre mot Azure Administrator (AZ-104).

Målet mitt er å utvikle kompetanse innen IT-drift, serveradministrasjon, skyteknologi og sikkerhet, med en langsiktig karriereretning innen Cloud Engineering.

## Teknologier

Porteføljenettsiden er utviklet med:

- **HTML5** – struktur og innhold.
- **CSS3** – design og responsiv layout.
- **JavaScript** – navigasjon, språkbytte og interaktivitet.
- **Git og GitHub** – versjonskontroll og kildekodelagring.

Nettsiden er statisk og krever ingen backend eller database.

## Funksjoner

- Responsivt design for PC, nettbrett og mobil.
- Norsk og engelsk språkvalg (NO/EN).
- Navigasjonsmeny med aktiv seksjonsmarkering.
- Fire prosjektkort med egne detaljsider.
- Lenker til GitHub-dokumentasjon og publiserte webapplikasjoner.
- Presentasjon av fagområder, sertifiseringer og kontaktinformasjon.

## Prosjekter

### 1. Azure Storage Lab

Praktisk Azure-prosjekt med Storage Account, privat Blob Container, Microsoft Entra ID, RBAC, nettverkssikkerhet, Azure Monitor og kostnadskontroll.

### 2. Azure Bicep – Infrastructure as Code

Praktisk læringsprosjekt med Azure Bicep og Azure CLI for automatisert opprettelse og administrasjon av Azure-ressurser.

### 3. Job Tracker

Fullstack webapplikasjon for administrasjon av jobbsøknader.

**Teknologier:** Java, Spring Boot, PostgreSQL, HTML, CSS og JavaScript.

**Nettside:** https://www.jobbsokertracking.no/

### 4. CleanPlan

Webapplikasjon for administrasjon av eiendommer, oppgaver, brukere og tilgangsstyring.

**Teknologier:** Supabase, PostgreSQL, HTML, CSS og JavaScript.

**Nettside:** https://anday2025.github.io/CleanPlan/

## Hosting og CI/CD

Planlagt videreutvikling:

- Hosting på Microsoft Azure Static Web Apps.
- Automatisk deployment med GitHub Actions.
- CI/CD for testing og publisering fra GitHub til Azure.
- Overvåking og kostnadskontroll i Azure.
- Videre læring innen Infrastructure as Code med Azure Bicep.

Implementerte funksjoner og resultater vil bli dokumentert etter hvert som de er testet.

## Lokal kjøring

Nettsiden kan kjøres lokalt med en enkel statisk webserver.

Åpne `Anday-Portfolio/index.html` via en lokal utviklingsserver for å teste nettsiden i nettleseren.

Ingen installasjon av backend eller database er nødvendig.
